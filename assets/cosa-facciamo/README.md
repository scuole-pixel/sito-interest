# Foto per la pagina "Cosa facciamo"

Carica qui le foto dei progetti (seminari in aula, eventi, team al lavoro).

Come caricarle:
- **Da GitHub**: apri questa cartella su github.com → `Add file` → `Upload files`.
- **In chat**: allega le immagini direttamente nella conversazione con Claude,
  che le ottimizza e le salva qui.

Convenzioni:
- Nomi in minuscolo con trattini, che dicano cosa mostrano:
  `seminario-liceo-tasso.jpg`, `team-workshop-roma.jpg`.
- Preferibile JPG/WebP, lato lungo ≥ 1600px; l'ottimizzazione la facciamo in fase
  di inserimento nella pagina.
