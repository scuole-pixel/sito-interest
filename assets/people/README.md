# Foto delle persone (governance)

Ritagli PNG **senza sfondo** (sfondo trasparente), figura intera o mezzo busto.
L'immagine viene appoggiata sul fondo del riquadro e mai tagliata dai bordi.

Nomi attesi: `nome-cognome.png` (es. `davide-dorigo.png`).
Se il file manca, la pagina mostra le iniziali.
