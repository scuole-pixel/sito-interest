# Foto delle persone (governance)

Ritagli **senza sfondo** (trasparenza reale), figura intera o mezzo busto,
formato WebP o PNG. L'immagine viene appoggiata sul fondo del riquadro e
mai tagliata dai bordi.

Nomi attesi: `nome-cognome.webp` (es. `davide-dorigo.webp`).
Se il file manca, la pagina mostra le iniziali.

Se la foto ha lo sfondo bianco invece che trasparente, va prima scontornata
(es. remove.bg) e poi salvata qui; conviene ridimensionarla a ~800px di
altezza per tenere il peso basso.
